This repository contains original curation and adaptation work plus third-party derived skills.

Rules:

- Canonical adapted skills live in `skills/<id>/`.
- Each adapted skill must include a `skill.yaml` file with upstream repository, path, commit, and license metadata.
- Upstream text may be edited for compatibility, clarity, and multi-environment portability, but source attribution must remain in metadata.
- Distribution packs in `dist/` are generated from the canonical adapted skills.

Do not add upstream content without recording its source location and license.
